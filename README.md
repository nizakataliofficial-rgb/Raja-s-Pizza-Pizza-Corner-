# 🍕 Raja's Pizza & Pizza Corner

A modern, fully responsive frontend web application designed for an online fast-food restaurant and pizza delivery service. This project delivers a seamless user experience inspired by top-tier food ordering platforms, complete with dynamic menus, active deal timers, and interactive cart management.

![Project Banner](https://images.unsplash.com/photo-1579751626657-72bc17010498?auto=format&fit=crop&w=1200&q=85)

## ✨ Features

- **Responsive Modern UI:** Clean, attractive layout optimized for desktops, tablets, and mobile devices.
- **Featured Promotional Banner:** High-quality food imagery showcasing fresh, hand-tossed pizzas.
- **Exclusive Deals Section:** Highlights limited-time offers (such as Midnight Deals) equipped with live countdown timers.
- **Interactive Cart & Order Summary:** Real-time calculation of totals and item management.
- **Customization & Delivery Modals:** Interactive flows for selecting delivery locations and customizing pizza toppings/sizes.
- **User Authentication & Rewards:** Built-in modal templates for customer sign-in, account creation, and loyalty tracking.

## 🛠️ Technologies Used

- **HTML5** – Semantic markup and structure
- **CSS3** – Modern styling, Flexbox/Grid, and custom UI components
- **JavaScript (ES6+)** – Dynamic DOM manipulation, cart logic, and interactive modals
- **Google Fonts & Unsplash** – Typography and high-resolution food assets
- **Git & GitHub** – Version control and deployment via GitHub Pages
